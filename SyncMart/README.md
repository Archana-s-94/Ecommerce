# SyncMart

SyncMart is a full-stack e-commerce web application.

## Technologies

- HTML
- CSS
- JavaScript
- EJS
- Node.js
- Express.js
- MySQL
- Express Session

## Setup

1. Install Node.js.
2. Run `npm install`.
3. Start XAMPP/MySQL.
4. Create a database named `syncmart`.
5. Import `database/syncmart.sql` using phpMyAdmin.
6. Check the database configuration in `dbconfig.js`.
7. Run the application using `node app.js`.
8. Open the application in the browser.

## Main Features

- User registration and login
- Product browsing
- Product categories
- Product search
- Product details
- Wishlist
- Shopping cart
- Checkout
- Orders
- User profile
